# -SMART-RESOURCE-MANAGEMENT-SYSTEM.

A simple **Python-based Smart Resource Management System** built using **Object-Oriented Programming (OOP)** concepts, dictionaries, lists, functions, loops, and conditional statements.

This project helps manage resources like food, water, medical kits, electricity, etc. It allows users to add, update, delete, and monitor resources efficiently through a command-line interface.

---

## Features

* View all available resources
* Add new resources
* Update existing resources
* Delete resources
* Low stock alert system
* Generate resource usage reports
* Simple menu-driven interface

---

## How It Works

The system stores all resources inside a list of dictionaries.

Each resource contains:

```python
{
    "name": "Food",
    "quantity": 500,
    "unit": "kg",
    "threshold": 200
}
```

The program continuously runs using a menu system until the user exits.
